09 — Lieferung & WordPress-Migration

Die 3 HTML-Dateien sind direkt browserfertig und können sofort dem Kunden gezeigt werden. Für die WordPress-Übergabe auf Ionos:

STACK

  • → WordPress 6.x auf Ionos Webhosting
  • → Custom Theme (kein Elementor, kein Divi)
  • → Tailwind CSS per CDN (Prototyp) oder NPM-Build
  • → ACF Lite für Portfolio Custom Post Type
  • → Contact Form 7 für Kontaktformulare
  • → Yoast SEO Free für Meta-Tags

MIGRATIONS-SCHRITTE

  1. WordPress auf Ionos installieren
  2. Leeres Custom Theme aus HTML-Dateien aufbauen
  3. header.php / footer.php aus Nav + Footer extrahieren
  4. front-page.php, page-produkte.php, page-service.php
  5. Portfolio als Custom Post Type + Archiv-Template
  6. CF7-Formulare einsetzen (Field-Names sind identisch)
  7. Logo + echte Fotos des Kunden einfügen
  8. Impressum + Datenschutz Seiten anlegen

FOTOS ERSETZEN

Alle <div class="photo"> durch <img src="..." alt="Beschreibung" loading="lazy" style="width:100%;height:100%;object-fit:cover;"> ersetzen. Format: WebP, max 1920px Breite. Client liefert Fotos per Ionos Drive oder WeTransfer.
